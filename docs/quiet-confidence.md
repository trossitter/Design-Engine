# Quiet confidence

Foundry assumes a keen, experienced user. The interface should feel composed enough to
be understood through structure, affordance, and response—not narration.

## Principles

1. **One idea per screen.** A heading sets the moment; the controls carry the task.
2. **State, don’t narrate.** Prefer “Draft PR #42 · open” to reassurance about what the
   user can already see or infer.
3. **Never say the same thing twice.** Keep one authoritative signal for status, risk,
   or ownership.
4. **Explain exceptions.** Copy earns its place when it describes a constraint, failure,
   destructive action, compliance risk, or recovery path.
5. **Reveal depth on demand.** Put secondary context behind details, tooltips, or the
   moment it becomes relevant.

## Copy test

Before adding a sentence, ask: could hierarchy, placement, state, or a better affordance
make it unnecessary? If yes, fix the interface and remove the sentence.
