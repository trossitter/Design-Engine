# Design Engine — live demo

Turn a finished page design into a live web page: drag in your design, and the engine
builds the section and opens it for preview and publish — no code, no command line.

**▶ Try it live: https://trossitter.github.io/Design-Engine/**

This is a working prototype of the product surface. The preview shown is the engine's
real generated output from a validated example; wiring live generation of any uploaded
design (and real pull requests) is the next build step.
